What you get

FieldExampleNotes

portRange "225-241" Reserved blocks, e.g. historically reserved ranges — filed under their start port

name "https" The IANA service name
description "http protocol over TLS/SSL" IANA's description, quoted verbatim
assignee "[IESG]" Assignee or contact, quoted verbatim (bracketed references included)
registrationDate "2012-07-31" ISO date, or null when not recorded

How it stays fresh

The update.yml workflow runs monthly, fetches service-names-port-numbers.csv from the IANA registry, regenerates the JSON and commits only when the data actually changed. GitHub Pages serves the result. No server to run.

Data source and accuracy

The IANA Service Name and Transport Protocol Port Number Registry is the authoritative list of port assignments. All 14,545 registry rows are included: 6,614 tcp, 6,360 udp, 93 sctp, 11 dccp, and 1,467 rows without a transport (deprecated or removed entries). It does not cover ephemeral ports that are unregistered, and it carries IANA's records verbatim — including bracketed references and historical notes. The CSV is parsed with an RFC 4180-compliant parser because IANA rows contain quoted fields with embedded commas and newlines.

Limits, stated plainly

  • The full dataset is ~3.2 MB — fine for a one-off fetch, but use the bucket files if you need one range at a time.
  • Deprecated and removed entries are kept with null fields rather than dropped, so the record count is larger than the number of usable ports.
  • IANA's CSV is the source of truth for dates and assignees; some rows are sparse or historical.
  • The registry is updated irregularly, so the monthly workflow may go many runs without a commit.
